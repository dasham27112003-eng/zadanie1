# Практическая работа 1 · Задымление

## Задача

Создать одностраничный информационный ресурс о техносферном риске «Задымление»:
краткое описание, признаки, действия «до / во время / после», блок «когда обращаться к официальной службе»,
первичные источники и отметка об учебных данных. Обязательное условие — полезная JavaScript-функция
(чек-лист действий с фильтром по этапу), доступная с клавиатуры и безопасно работающая с DOM.

## Инструкция запуска

1. Скачайте или склонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Дополнительные библиотеки не требуются. Для работы JavaScript-функции не нужен сервер —
   страница работает локально.

## Ограничения

- Материал носит **учебный** характер и не является официальной инструкцией.
- Чек-лист сохраняет в `localStorage` только факт отметки пунктов; персональные данные не собираются.
- Список источников ограничен открытыми страницами МЧС России и Роспотребнадзора.
  Перед реальным использованием в конкретном регионе рекомендуется сверить рекомендации
  с местными органами власти.

## Журнал применения ИИ

**Задача, переданная помощнику:**
Составить план одностраничного сайта на тему «Задымление» с семантической разметкой,
адаптивной вёрсткой и JavaScript-функцией чек-листа с фильтром по этапу.

**Один существенный запрос:**
«Предложи структуру HTML-страницы о задымлении: разделы, заголовки, список источников.
Нужна доступная фильтрация чек-листа с клавиатуры и сохранением состояния в localStorage
без персональных данных».

**Как проверяли результат:**
- Сверили каждый пункт чек-листа и блок «когда обращаться» с официальными страницами МЧС России
  и Роспотребнадзора (ссылки в таблице выше).
- Проверили работу фильтра с клавиатуры: кнопки доступны по Tab, активное состояние
  обозначается не только цветом (атрибут `aria-pressed`).
- Убедились, что пользовательский ввод и внешние строки выводятся через `textContent`,
  а не через `innerHTML`.

**Что исправили самостоятельно:**
- Убрали формулировки, которые могли выглядеть как постановка диагноза, заменили на
  описание признаков и условий.
- Добавили `hidden` для скрытых пунктов чек-листа вместо управления только стилями.
- Уточнили, что данные в `localStorage` не содержат персональной информации.

**Какие данные сознательно не передавали модели:**
Персональные данные, контакты, внутренние документы организации, а также любые
сведения, не относящиеся к открытым источникам по теме задымления.
